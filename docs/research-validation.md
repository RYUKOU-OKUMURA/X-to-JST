## 自動チェック

- `npm run check`：型検査・既存JSTを含む145テスト・ビルド。
- `CHROMIUM_PATH='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome' npm run test:browser`：コンパイル済みUI＋mock runtime。
- 同じ環境の `npm run test:chrome`：Chrome 154.0.8037.97、実MV3＋隔離した一時プロファイル＋固定X DOM。
- 実拡張で明示収集・選択保存・メモ・ページ再読み込み・同一プロファイルのブラウザ再起動後の本文/メモ/URL保持を確認。JSON書き出しの形式・キー不在と、同じバックアップの復元後のメモ保持を確認。
- storageのcontent scriptアクセス拒否、キーのX DOM不在、既存JST・SPA追加投稿・コピーを維持。中断後の遅延結果、キャッシュの全バッチ再利用と目的変更、関連探索へ移る際の収集停止、同一URLで収集元タブが変わる場合の停止は自動テストで確認。

smokeは固定DOMを使う。ツールバークリック・実XのDOM・有料Jev呼び出しを確認したテストとは扱わない。スクリーンショットとJSON結果はignoredの `test-results/` に出力する。

## 利用中のCometで確認した範囲

- 既存拡張の読込先は本リポジトリの `dist/`。現在の権限内でパネル入口を追加。
- 単独投稿の現在の日本語表示本文・言語・投稿日時・URLを取得。英語原文を取得したとはしない。
- ブックマークURLは現在のXでは `/i/history` に遷移し、選択中の「ブックマーク」タブを識別。最初の表示では5件取得、引用の所有関係が不明な1要素を拒否。手動スクロールで20件を取得し、選択保存した。
- 修正前の検索基準で、20件に対しユーザー指定の7テーマをJevで評価。各検索はおよそ0.2〜0.3秒、入力6,121〜6,141/出力314トークン。これらは当該20件の観測値で、200件時の速度や料金保証ではない。
- Google Workspace活用の検索ではWorkspace Studio＋Webhook＋GASの投稿が先頭になった。一方、ChatGPT検索でClaude Code投稿が上位に混ざる誤判定を観測。
- 読み込み済みの旧基準でWorkspace活用投稿を比較元にした関連探索も実測。保存19件に対し候補0件、0.4秒、入力7,873/出力1,245トークン。異なるツールの投稿に「無関係」と表示された。続報・変更の正例を判別できると確認した結果ではない。

指定テーマ：AIの自動化活用、Google Workspace活用、Claude Code、ChatGPT、OpenClaw/Grok botなどのAIエージェント、個人開発、プログラミング知識。

## 修正と残件

- Jevの基準を修正し、質問ごとの対象投稿を限定、別投稿を根拠にしないこと、製品名を指定した目的で別ブランドへ置き換えないことを明記。**指示の修正は確認済みだが、誤判定の解消は未確認。**
- その後Cometの拡張管理画面が空白になった。既存タブの再読み込み・一覧/詳細移動・新しい管理タブ・デバッグ接続解除を試しても操作可能な管理UIを再表示できず、最新版を再読み込みした証拠が得られていない。別Chromeでの成功をCometの復旧として扱わない。
- 最新ビルドのComet再読み込み後、同じ20件・同じChatGPT目的を再評価し、製品名違いと該当なしを確認する。関連探索の最新版と続報・変更の正例は未確認。関係ラベルは「候補」で、原文以上の事実を断定しない。
- 実利用100〜200件、5つの探し物の期待投稿が4つ以上で上位5件に入る評価は未実施。7テーマは本人指定済みだが、期待する具体的投稿と本人の有用性評価は未取得。完成判定の性能目標を達成済みとはしない。
